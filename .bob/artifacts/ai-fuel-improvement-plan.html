Visual Improvements

Visual Animated Budget Bar
Replace static bar with a segmented, animated bar that ticks down in real-time during execution. Color transitions: green → yellow → red as budget depletes.
Visual Task Cards Redesign
Replace plain rows with cards that have a left color stripe per priority, mode icon, and a micro chart showing relative cost vs. total budget.
Visual Execution Timeline
Vertical stepper with connecting animated line. Active step pulses. Completed steps show checkmark with elapsed time. Error step glows red.
Visual TRACE Dependency Graph
SVG node graph showing which files/modules are affected by the fix. Nodes colored by impact severity. Replaces the plain checkbox list.
Visual Onboarding Empty States
Illustrated empty states for each page when no data exists. Guides user to the next action rather than a blank screen.
Visual Budget Float Badges
Enhance existing float badges — add color (red for deductions, green for resets), larger font, and a brief blur-in animation for delight.

Technical Improvements

Technical Streaming AI Response
Use watsonx.ai streaming API so tasks appear one-by-one as the model generates them instead of waiting for the full response. Use SSE or chunked transfer.
Technical Persistent State
Save WorkflowContext to sessionStorage so refreshing the page doesn't lose the current plan and analysis. Budget state synced with backend on every change.
Technical Real Execution Logs
Backend generates step-specific logs from watsonx.ai for each task (e.g. actual OAuth fix steps). Currently hardcoded to 5 generic steps.
Technical Route Guards
Prevent direct navigation to /analysis, /execution, /plan without valid state. Redirect back to Workspace with a clear message instead of a broken empty page.
Technical Real Impact Analysis
The /impact and /trace routes currently return hardcoded mock data. Wire them to watsonx.ai to return real diagnosis based on the actual error encountered during execution.
Technical API Error Toasts
Add a global toast/notification system for API errors. Currently errors are silently swallowed into mock fallbacks with no user feedback.

New Features

New Task History
A history page showing past submitted requests, their cost, and outcome. Stored in localStorage. Helps users learn from past budget decisions.
New Budget Forecast
After analysis, show a chart: "At this usage rate, your budget runs out in X days." Gives developers a planning horizon.
New Custom Task Editor
Let users manually add, edit, or remove tasks from the AI-generated plan before execution. Includes cost slider and mode selector.
New AI Mode Explainer
Tooltip/modal explaining what Lightweight, Balanced, and Advanced AI modes mean in terms of model quality, speed, and cost — so users can make informed choices.
