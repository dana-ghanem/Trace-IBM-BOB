Fix watsonx.ai — Associate WML Service

Your project returns 403 because it has no Watson Machine Learning instance linked.

Root cause: no_associated_service_instance_error — project 566d0899-d717-49fb-b9b3-6f9edb9bf1b5 is not associated with a WML instance.
1
You are already here — click "Services & integrations" YOU ARE HERE
In the left sidebar of your AI fuel project → Manage tab → click Services & integrations.
2
Click "Associate service"
A button labeled Associate service (or + Add service) will appear on that page. Click it.
3
Select Watson Machine Learning
From the list of available services, select your Watson Machine Learning instance. If none exists, click New service → choose Watson Machine Learning → pick the Lite (free) plan → create it.
4
Click "Associate"
Confirm the association. The WML instance will now appear under Services & integrations for this project.
5
Restart the backend
In your terminal inside ai-fuel-backend/, stop the server and run node server.js again. The real watsonx.ai tasks will now appear instead of the hardcoded fallback.
✅ After this fix, submitting "fix the api, add security, fix ui/ux" will return AI-generated tasks from IBM Granite — not the hardcoded fallback list.
